react-generic-tools 0.0.141

Project status

Use case

A collection of small React helpers shared by the author's React libraries: hooks for stable values and references, an unstyled pagination component, debugging hooks to find out why a component renders again, a minimal unit test environment for components and hooks and helpers for end-to-end tests with Playwright.

Content

Installation

npm install react-generic-tools clientnode core-js react react-dom

The test helpers additionally need "jest" with a "jsdom" test environment, the end-to-end helpers need "@playwright/test".

Hooks

  • "useMemorizedValue(value, ...dependencies)": Returns the value of the first render until one of the dependencies changes. Useful for object or function literals which should keep their identity.
  • "useReferenceState(initialValue)": Like "useState", but the setter ignores "null". Pass the setter as callback reference to keep the last mounted element in state.
import {useMemorizedValue, useReferenceState} from 'react-generic-tools'

export const Measured = () => {
    const [element, setElement] =
        useReferenceState<HTMLDivElement | null>(null)
    const style = useMemorizedValue({padding: '1em'})

    return <div ref={setElement} style={style}>
        {element ? `${element.offsetWidth}px wide` : null}
    </div>
}

Pagination

"Pagination" renders a list of page items without any styling. "total" is the number of entries, "pageSize" the number of entries per page and "page" the current page. "render" decides what each item shows:

import {Pagination} from 'react-generic-tools'

<Pagination
    page={page}
    pageSize={10}
    render={({disabled, page: target, selected, type}) =>
        type.endsWith('ellipsis') ?
            '…' :
            <button
                disabled={disabled || selected}
                onClick={() => setPage(target as number)}
            >{type === 'page' ? target : type}</button>
    }
    total={entries.length}
/>

Further properties are "boundaryCount" and "siblingCount" (number of pages shown at the ends and around the current page), "showFirstButton", "showLastButton", "hidePrevButton", "hideNextButton", "disabled" and "className". Nothing is rendered if everything fits on one page.

Debugging

"useLogChanges" logs which parts of a value changed since the last render. Put it into a component which renders more often than expected:

import {useLogChanges} from 'react-generic-tools/debugHelper'

export const Expensive = (properties: Properties) => {
    useLogChanges(properties, 'Expensive properties')
    // ...
}

"useOldValue" returns the value of the previous render and "getChanges" compares two values without React.

Unit tests

"prepareTestEnvironment" mounts a fresh React root before and removes it after each test. "render" returns the first rendered DOM node, "runHook" calls a hook inside a test component:

import {afterEach, beforeEach, expect, test} from '@jest/globals'
import {useState} from 'react'
import prepareTestEnvironment from 'react-generic-tools/testHelper'

const {render, runHook} = prepareTestEnvironment(beforeEach, afterEach)

test('renders a button', () => {
    expect(render(<button>Save</button>)?.textContent).toBe('Save')
})

test('runs a hook', () => {
    const {result} = runHook(useState, {parameters: [2]})

    expect(result.value[0]).toBe(2)
})

The returned "render" function of "runHook" renders again with new parameters. With "wrapper" the hook runs inside a provider component.

End-to-end tests

Helpers for Playwright tests in "react-generic-tools/endToEndTestHelper":

  • "formatEndUserDate(date)" and "formatEndUserTime(date)": Format values the way Playwright expects them for date and time inputs.
  • "waitForFinishedLoading(page, spinner)": Waits for network idle and an optional loading indicator to disappear.
  • "forwardLogging(page)": Prints the browser console to the test output.
  • "isSameLocator(first, second)": Checks whether two locators point to the same element.
import {expect, test} from '@playwright/test'
import {
    formatEndUserTime, forwardLogging
} from 'react-generic-tools/endToEndTestHelper'

test('sets the start time', async ({page}) => {
    forwardLogging(page)
    await page.goto('/')

    const time = formatEndUserTime(new Date())
    await page.getByLabel('Start').fill(time)

    await expect(page.getByLabel('Start')).toHaveValue(time)
})
